# Hello Python App

This is a simple Python application that prints "Hello, World!" to the console.

## Project Structure

```
hello-python-app
├── src
│   └── hello.py
├── tests
│   └── test_hello.py
├── requirements.txt
├── pyproject.toml
├── .gitignore
└── README.md
```

## How to Run the Application

1. Navigate to the project directory.
2. Run the application using the following command:

   ```
   python src/hello.py
   ```

## How to Run Tests

1. Ensure you have the necessary testing framework installed (e.g., pytest).
2. Run the tests using the following command:

   ```
   pytest tests/test_hello.py
   ``` 

## Dependencies

This project may have dependencies listed in `requirements.txt`. Please install them using:

```
pip install -r requirements.txt
```
